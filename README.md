
# News Text Classification Using Naive Bayes

## Project Overview
This project classifies news text into four categories using
the Multinomial Naive Bayes machine learning algorithm.

## Categories
- Sports
- Technology
- Business
- Politics

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Multinomial Naive Bayes
- Flask
- HTML and CSS

## Project Features
- Text preprocessing and feature extraction
- Model training and evaluation
- Prediction of new text categories
- Model saving using Joblib
- Simple web interface using Flask

## Installation
1. Clone this repository.
2. Create and activate a virtual environment.
3. Install the dependencies:

   pip install -r requirements.txt

4. Train the model:

   python main.py

5. Start the web application:

   python app.py

6. Open http://127.0.0.1:5000/ in your browser.

## Dataset
The sample dataset contains labelled news text
belonging to four categories.

## Machine Learning Workflow
Dataset → TF-IDF → Naive Bayes → Evaluation → Prediction
